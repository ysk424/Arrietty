# Arrietty Roadmap

最終更新: 2026-08-26

## Version 0.7.0 — ステム計器盤

実装済み。右OpenXR/OpenVRグリップの最初の有効位置を自転車ローカル座標へ一度だけ校正し、コントローラー位置がない間は仮想ステムへフォールバックする。表示の安定性を優先して生の6DoF位置・回転は継続反映せず、黒い背景板を使わない緑・オレンジの発光文字だけの構成とする。

HMDへ固定したHUDではなく、ステムに固定した右コントローラの近くへ、実車のサイクルコンピュータのような計器盤を表示する。

表示項目:

- 現在速度（km/h）
- 心拍数（bpm。センサー未接続時は`-- bpm`）
- 現在時刻
- ケイデンス（rpm）
- パワー（W）
- 総走行距離（mまたはkm）
- 完了周回数
- 高度（m）
- 地上／飛行モード
- ローカルX/Y位置

計器盤は右コントローラ位置へ追従する。視界中央へ常時重ねず、ステムを見ると読める位置へオフセットする。速度を最も大きく、心拍と時計を次に大きく表示し、その他を補助情報にする。T2の速度・ケイデンス・パワーと現在の走行状態は既存ランタイムから受け取る。心拍受信は独立した将来モジュールから値を渡せるようにし、未接続時は`-- bpm`とする。

## Version 0.8.0 — 空

入力項目:

- 日付
- 時刻
- 緯度

入力から太陽と空の見え方を作る。Arriettyでは12:00の太陽を天頂に置くことを表示規則とし、日の進行を時刻へ連動させる。緯度は太陽の軌道と空の向きへ反映する。夜間を含む明るさ、空色、太陽の表示を一体として扱う。

Version 0.8.0の空をもってArriettyを機能完了とする。

## 入力装置と人力飛行機モデル

3個の物理ボタンを使う構想がある。暫定割り当てはブレーキ、エレベーター機首上げ、エレベーター機首下げとし、ボタンを離した状態を中立とする。接続方式と入力コードが確定してから実装する。

地上走行はP5/Crr 0.020をロードバイク初期値とする。飛行中は路面Crrを飛行物理へ流用せず、対気速度に応じた抗力と揚力を計算し、エレベーター入力で上昇・水平・下降を制御する人力飛行機モデルへ発展させる。

## Arrietty完了後 — Secret World

Google由来の世界を作る機能はArriettyへ追加せず、別のBlenderプラグイン「Secret World」として開発する。APIと利用規約、キャッシュ容量、座標参照系、原点移動、実寸スケールを独立して設計し、必要な場合だけArriettyと組み合わせる。
